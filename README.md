## 🛠 Технологии

- React 18
- TypeScript
- Tailwind CSS 4
- Framer Motion
- React Router
- React Hook Form + Zod

## 🚀 Локальный запуск

```bash
npm install
npm run dev
```

## 📦 Сборка

```bash
npm run build
```

Результат в папке `dist/`
